# Интернет-магазин (ООП на Python)

Проект по разработке системы управления товарами и категориями интернет-магазина. Реализован на языке Python с глубоким применением принципов объектно-ориентированного программирования (ООП).

## 🚀 Основной функционал

В проекте реализована логика управления ассортиментом:

*   **Класс `Product`**:
    *   **Магические методы**:
      ```
      __str__: удобное отображение товара (Название, 100 руб. Остаток: 5 
        шт.).
      __add__: возможность складывать товары. Результат — полная стоимость 
      всех единиц двух товаров на складе.
      ```
    *   **Инкапсуляция цены**: атрибут цены защищен (`private`). Доступ реализован через геттер и сеттер.
    *   **Валидация**: цена не может быть нулевой или отрицательной.
    *   **Защита от ошибок**: при снижении цены система запрашивает подтверждение у пользователя через консоль.
    *   **Умное создание**: метод `new_product` умеет объединять дубликаты (складывает количество и выбирает максимальную цену).

*   **Класс `Category`**:
    *   **Магические методы**:
    ```
        __str__: отображает название и общее количество всех единиц товара в 
        категории.
        __len__: возвращает суммарное количество всех товаров на складе для 
        данной категории.
    ```
    *   **Приватный список товаров**: прямой доступ к списку ограничен.
    *   **Форматированный вывод**: геттер возвращает список товаров в строковом виде: `Название, 100 руб. Остаток: 5 шт.`
    *   **Статистика**: автоматический подсчет общего количества уникальных товаров и категорий.

*   **Иерархия и наследование**:
    *   **Базовый класс `Product`**: содержит общую логику для всех товаров (имя, цена, остаток).
    *   **Класс `Smartphone`**: расширяет базовый функционал специфическими характеристиками: производительность, модель, объем памяти и цвет.
    *   **Класс `LawnGrass`**: специализированный класс для садовых товаров с атрибутами страны-производителя, срока прорастания и цвета.
    *   **Строгая типизация при сложении**: реализована защита на уровне метода `__add__`. Система позволяет складывать только товары одного и того же класса (например, смартфон со смартфоном), предотвращая логические ошибки при расчете стоимости остатков.
    *   **Валидация при добавлении**: метод `add_product` в категориях проверяет, является ли объект экземпляром класса `Product` или его наследником, исключая попадание некорректных данных в систему.
    
*   **Загрузка данных**: реализована функция `load_data_from_json` для автоматического создания объектов из внешних файлов.

## 🛠 Технологии и стандарты

Проект соответствует высоким стандартам разработки:
*   **PEP 8**: Полное соответствие правилам оформления кода (проверено через `flake8`).
*   **Mypy**: Проект полностью типизирован. Используются аннотации типов для всех методов и атрибутов.
*   **Poetry**: Современное управление зависимостями и виртуальным окружением.

## 📥 Установка

1.  **Клонируйте репозиторий**:
    ```bash
    git clone git@github.com:lenaLeshukova/online-store.git
    ```
2.  **Установите зависимости** (требуется Poetry):
    ```bash
    poetry install
    ```
