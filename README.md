# Интернет-магазин
Проект по разработке системы управления товарами и категориями интернет-магазина на Python с использованием ООП.

## Функционал

В проекте реализованы базовые сущности для работы интернет-магазина:
*   **Класс `Product`**: хранит информацию о названии, описании, цене и количестве товара.
*   **Класс `Category`**: группирует товары, хранит их список и ведет автоматический учет общего количества категорий и уникальных товаров.
*   **Загрузка из JSON**: автоматическое создание объектов классов из внешних файлов данных.

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:lenaLeshukova/online-store.git
```
2. Установите зависимости:
```
bash
poetry install
```

## Тестирование
